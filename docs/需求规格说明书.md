## 2. 引言

### 2.1 编写目的
本文档详细描述了记账本桌面应用的功能需求、非功能需求以及系统约束，为软件开发、测试和验收提供依据。

### 2.2 项目背景
本项目是一个面向个人用户的跨平台桌面记账本程序（Windows / macOS / Linux），帮助用户记录日常收入和支出，进行财务统计分析和数据管理。

### 2.3 术语定义

| 术语 | 说明 |
|------|------|
| 账单记录 | 一条包含日期、类型、分类、金额、备注的收支记录 |
| 收支类型 | 分为"收入"和"支出"两种 |
| 分类 | 对账单进行细分的类别，如餐饮、交通等 |
| 导入映射 | 将外部文件列与系统字段对应的过程 |
| 数据库路径显示 | 在界面状态栏显示当前打开的数据库文件路径 |

## 3. 总体描述

### 3.1 系统目标
开发一个简洁高效的跨平台桌面记账本程序，支持收入/支出账单管理、可视化统计与数据导出。

### 3.2 用户特征
- 个人用户，需要记录日常收支
- 具备基本的计算机操作能力
- 希望快速导入支付宝、微信等第三方账单
- 需要管理多个账本文件

### 3.3 运行环境
- **操作系统**: Windows 7/10/11、macOS、Linux（Linux 需安装 python3-tk）
- **运行环境**: Python 3.8+
- **硬件要求**: 2GB RAM，100MB 磁盘空间

### 3.4 约束条件
- 单机版应用，不支持多用户协作
- 数据存储在本地 SQLite 数据库
- 界面语言为中文

### 4.2 功能需求详细说明

#### 4.2.1 账单管理模块

##### FR-001 添加账单
- **优先级**: 高
- **描述**: 用户可以添加一条新的收支记录
- **输入**: 日期、类型(收入/支出)、分类、金额、备注
- **处理**: 
  - 验证金额为有效数字
  - 日期格式化为 YYYY-MM-DD
  - 保存到 DataFrame 并标记数据变更
  - 记录操作日志
- **输出**: 账单列表刷新，显示添加成功提示

##### FR-002 编辑账单
- **优先级**: 高
- **描述**: 用户双击表格行可编辑账单
- **输入**: 修改后的字段值
- **处理**: 更新 DataFrame 对应记录
- **输出**: 列表刷新，自动保存到数据库

##### FR-003 删除账单
- **优先级**: 高
- **描述**: 支持单条删除和批量删除
- **处理**: 
  - 二次确认弹窗
  - 支持多选删除
  - 更新 DataFrame
  - 记录操作日志
- **输出**: 删除成功提示

##### FR-004 查看账单列表
- **优先级**: 高
- **描述**: 以表格形式展示所有账单
- **特性**:
  - 支持点击表头排序
  - 双击行编辑
  - 多行选择
  - 滚动条支持

##### FR-005 筛选查询
- **优先级**: 中
- **筛选条件**:
  - 日期范围（起始日期、结束日期）
  - 金额范围（最小金额、最大金额）
  - 类型（全部/收入/支出）
  - 分类（全部/具体分类）
- **输出**: 筛选后的列表展示

#### 4.2.2 数据导入模块

##### FR-006 CSV文件导入
- **优先级**: 高
- **描述**: 导入标准格式 CSV 文件
- **输入格式要求**:
  ```
  日期,类型,分类,金额,备注
  2025-01-01,收入,工资,10000,无
  ```
- **处理流程**:
  1. 读取 CSV 文件
  2. 精细化异常处理（文件不存在、编码错误、空文件、解析错误）
  3. 弹出列映射对话框
  4. 数据预览和编辑
  5. 确认导入

##### FR-007 支付宝账单导入
- **优先级**: 高
- **描述**: 导入支付宝账单 CSV
- **特殊处理**:
  - 自动跳过前24行说明
  - 使用 GBK 编码读取
  - 自动识别列名（中英文兼容）
  - 收支类型映射（收/支 → 收入/支出）
  - 精细化异常处理

##### FR-008 微信账单导入
- **优先级**: 高
- **描述**: 导入微信账单 Excel
- **特殊处理**:
  - 自动跳过前16行说明
  - 从第17行开始读取数据
  - 去除金额中的 ¥ 符号
  - 类型识别（收入/入账 → 收入）
  - 精细化异常处理

##### FR-009 导入预览和编辑
- **优先级**: 中
- **描述**: 导入前预览数据并支持编辑
- **功能**:
  - 显示前10行预览
  - 点击表头排序
  - 双击行编辑修改
  - 确认/取消导入

#### 4.2.3 数据统计模块

##### FR-010 月度账单统计
- **优先级**: 高
- **描述**: 按月份汇总收支数据
- **输出字段**: 月份、收入、支出、总收入、总支出
- **特性**: 
  - 支持点击表头排序
  - 双击查看当月明细

##### FR-011 月度收支柱状图
- **优先级**: 中
- **描述**: 展示每月收入和支出的对比柱状图
- **图表类型**: 分组柱状图
- **X轴**: 月份
- **Y轴**: 金额

##### FR-012 单月分类饼图
- **优先级**: 中
- **描述**: 展示指定月份收支分类占比
- **图表类型**: 饼图（左右并列显示收入和支出）
- **特性**: 支持切换上一月/下一月

#### 4.2.4 系统管理模块

##### FR-013 新建账本
- **优先级**: 高
- **描述**: 创建新的数据库文件
- **处理**: 未保存数据提示保存，创建后更新状态栏显示
- **输出**: 新建成功提示，状态栏更新为新路径

##### FR-014 打开账本
- **优先级**: 高
- **描述**: 切换不同的数据库文件
- **默认路径**: ./database/ 目录
- **处理**: 打开后更新状态栏显示当前路径

##### FR-015 保存数据
- **优先级**: 高
- **描述**: 将当前数据保存到数据库
- **机制**: 全量覆盖写入，批量插入优化
- **异常处理**: 失败时回滚事务

##### FR-016 另存为
- **优先级**: 中
- **描述**: 将数据保存到新的数据库文件
- **处理**: 保存后切换到新数据库，更新状态栏显示

##### FR-017 导出CSV
- **优先级**: 中
- **描述**: 将所有数据导出为 CSV 文件
- **编码**: UTF-8 with BOM

##### FR-018 退出保护
- **优先级**: 高
- **描述**: 退出时检查未保存数据并提示

##### FR-019 状态栏显示当前数据库路径
- **优先级**: 中
- **描述**: 在窗口底部状态栏显示当前打开的数据库文件路径
- **显示规则**:
  - 显示绝对路径
  - 路径超过50字符时自动截断，显示后半部分
  - 支持悬浮提示显示完整路径（可选）
- **更新时机**:
  - 应用启动时
  - 打开数据库后
  - 新建数据库后
  - 另存为后

## 6. 数据需求

### 6.1 数据实体

#### 6.1.1 账单记录 (Record)

| 字段名 | 数据类型 | 是否必填 | 说明 |
|--------|---------|---------|------|
| id | INTEGER | 是 | 主键，自增 |
| 日期 | TEXT | 是 | 格式：YYYY-MM-DD |
| 类型 | TEXT | 是 | 收入/支出 |
| 分类 | TEXT | 是 | 预定义分类或自定义 |
| 金额 | REAL | 是 | 正数 |
| 备注 | TEXT | 否 | 补充说明 |

#### 6.1.2 数据库索引

| 索引名 | 字段 | 用途 |
|--------|------|------|
| idx_date | 日期 | 加速日期范围查询 |
| idx_type | 类型 | 加速类型筛选 |
| idx_category | 分类 | 加速分类筛选 |

CATEGORIES = ['餐饮', '交通', '购物', '娱乐', '医疗', '住房', '学习', '工资', '其他']
