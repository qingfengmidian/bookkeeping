## 一、设计哲学

参考 Things/Notion/Bear 等极简工具的设计语言，落到 tkinter 可实现的程度：

1. **色彩即层级**：不用边框和分组框划分区域，用留白和背景色明度差分区
2. **一屏一焦点**：主按钮只有一个（添加），其余操作弱化
3. **语义色克制**：红/绿只出现在"金额数字"上，界面其余部分近乎单色
4. **字体即排版**：通过字重和字号建立层级，不用图标堆砌
5. **一切从简**：去掉 LabelFrame 的立体边框、Treeview 的竖线、按钮的默认浮雕

## 二、配色系统

| 角色 | 色值 | 用途 |
|------|------|------|
| `BG` | `#FFFFFF` | 窗口主背景 |
| `BG_SUBTLE` | `#F7F7F5` | 输入区/统计区背景（比纯白低一档，无描边） |
| `BORDER` | `#E5E5E3` | 仅有的两种描边：输入框、表格横线 |
| `TEXT` | `#1A1A1A` | 主文字 |
| `TEXT_MUTED` | `#8A8A86` | 次要文字（表头、提示、数据库路径） |
| `ACCENT` | `#2563EB` | 唯一强调色：主按钮、选中行、当前排序列 |
| `ACCENT_HOVER` | `#1D4ED8` | 主按钮悬停 |
| `INCOME` | `#059669` | 收入金额/收入柱 |
| `EXPENSE` | `#DC2626` | 支出金额/支出柱 |
| `ROW_STRIPE` | `#FAFAF8` | 表格斑马行 |
| `ROW_SELECTED` | `#EFF4FF` | 表格选中行（ACCENT 的 8% 透明度感） |

规则：强调色全界面只出现在"主按钮 + 选中态"两处；红绿只在数字和图表里。

## 三、字体与层级

跨平台字体栈（替代现有写死的"微软雅黑"——macOS/Linux 上该名称无效）：

```python
FONT_FAMILY = ['Helvetica Neue', 'PingFang SC', 'Microsoft YaHei', 'Noto Sans CJK SC', 'sans-serif']
```

| 层级 | 规格 | 用于 |
|------|------|------|
| `H1` 16px 中等 | 窗口标题（系统托管，不处理） |
| `BODY` 13px | 正文、表格内容、输入框 |
| `CAPTION` 11px | 表头、统计区说明、数据库路径 |
| `NUMERIC` 13px | 金额列（等宽数字效果：`font` 带 `tabular` 特性不可控，退而求其次用统一字号+右对齐） |

## 四、组件级改造清单

### 4.1 主窗口（ui/main_window.py `create_widgets`）

**现状问题**：LabelFrame 立体边框、所有控件一行挤在网格里、按钮无主次。

**方案**：

1. **输入区**：去掉 LabelFrame 边框 → 一个 `BG_SUBTLE` 背景的平面 Frame，内部字段纵向基线对齐（label 在上、控件在下 或保持横排但统一 8px 间距）；「添加」改为主按钮（实心 ACCENT、白字），放在输入区右端
2. **表格区**（改动最大）：
   - 去掉竖线（`displaycolumns` + `column` 设置），只保留横线（`BORDER` 色）
   - 斑马行：奇偶行 `ROW_STRIPE` / 白（Treeview tag 实现）
   - 表头：`TEXT_MUTED` 11px、无边框、点击排序后当前列标题变 ACCENT
   - 金额列右对齐，类型列用语义色（收入绿/支出红文字）
   - 行高增至 32px（`Treeview.rowheight`），呼吸感
3. **操作区**：「删除选中」降为文字按钮（无边框、EXPENSE 色文字、悬停加底色）；「删除全部」降为 `TEXT_MUTED` 文字按钮，与删除选中拉开间距，弱化误触
4. **统计区**：平面 `BG_SUBTLE` 底栏，总收入/总支出用大号数字（INCOME/EXPENSE 色）+ CAPTION 说明文字；数据库路径缩为 10px `TEXT_MUTED`，右侧一个数据库小图标位置（暂不引入图标字体，仅文字）
5. **窗口**：最小尺寸 960×640，启动居中

### 4.2 对话框（ui/dialogs.py）

统一约定：白底、标题 14px、内容区间距 16px、底部右对齐按钮组（主按钮在右）、所有对话框固定宽度 420px（预览对话框 720px）。

- 输入框统一高度 32px、圆角不可实现（tkinter 限制）、聚焦时边框变 ACCENT（clam 主题可配置）
- 筛选对话框：字段纵向排列、label 用 CAPTION 色

### 4.3 图表（ui/charts.py）

- 统一图表配色：收入 `INCOME`、支出 `EXPENSE`、分类饼图用同系低饱和色板（`#2563EB/#60A5FA/#93C5FD/#059669/#34D399/#F59E0B...` 按序取）
- 去边框（`spines` 隐藏上/右）、网格线仅 Y 轴虚线 `BORDER` 色
- 背景透明/白，标题 14px 左对齐，`unicode_minus=False` 已有

### 4.4 主题实现方式（技术方案）

新增 `ui/theme.py`：

```python
def apply_theme(root):
    style = ttk.Style(root)
    style.theme_use('clam')          # clam 是唯一可深度定制的内置主题
    # 依次配置 TFrame/TLabel/TButton/TEntry/TCombobox/Treeview...
    # 所有色值引用 ui/theme.py 顶部的常量，禁止散落硬编码
```

- 入口：`main.py` 创建 root 后、实例化 RecordBook 前调用 `apply_theme(root)`
- `RecordBook.__init__` 与 dialogs 全部改为引用主题常量，删除局部 `style.configure` 散落代码
- 深色模式：留接口不实现（v2 候选，tkinter 可做但需双倍配色维护）

## 六、明确不做的事

- 不引入自定义图标字体/图片资源（tkinter 资源管理弱，会显著增加打包体积）
- 不做圆角窗口/毛玻璃（需第三方库，破坏纯标准库+现有依赖的简洁性）
- 不做深色模式 v1（维护成本翻倍，需求不明确）
- 不改任何交互逻辑和数据库结构
