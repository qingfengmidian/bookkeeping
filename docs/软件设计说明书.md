## 3. 系统架构设计

### 3.1 架构模式
采用**分层架构模式（Layered Architecture）**，将系统分为以下四层：

```
┌─────────────────────────────────────────────┐
│              表示层 (Presentation)            │
│  ┌─────────────┐ ┌───────────┐ ┌─────────┐  │
│  │ main_window │ │  dialogs  │ │ charts  │  │
│  └─────────────┘ └───────────┘ └─────────┘  │
├─────────────────────────────────────────────┤
│              业务逻辑层 (Business Logic)      │
│  ┌─────────────────────────────────────┐    │
│  │          record_model               │    │
│  │   (数据处理、统计计算)               │    │
│  └─────────────────────────────────────┘    │
├─────────────────────────────────────────────┤
│              数据访问层 (Data Access)         │
│  ┌─────────────────────────────────────┐    │
│  │            database                 │    │
│  │   (SQLite 数据库操作)                │    │
│  └─────────────────────────────────────┘    │
├─────────────────────────────────────────────┤
│              工具层 (Utilities)               │
│  ┌─────────────────┐ ┌─────────────────┐    │
│  │    constants    │ │     logger      │    │
│  │   (常量、配置)   │ │  (日志配置模块)  │    │
│  └─────────────────┘ └─────────────────┘    │
└─────────────────────────────────────────────┘
```

### 3.2 模块划分

| 模块名 | 路径 | 职责 |
|--------|------|------|
| 主入口 | main.py | 程序启动，初始化GUI和日志系统 |

#### 4.4.2 支付宝导入特殊处理
```python
def _build_alipay_mapping(self, columns: list) -> dict:
    """构建支付宝账单的默认列映射"""
    
def _transform_alipay_data(self, df: pd.DataFrame) -> pd.DataFrame:
    """支付宝数据自动转换"""
    df['类型'] = df['类型'].map(lambda x: '收入' if '入' in str(x) else '支出')
    df['分类'] = df['分类'].fillna('支付宝')
    return df
```

#### 4.4.3 微信导入特殊处理
```python
def _build_wechat_mapping(self, columns: list) -> dict:
    """构建微信账单的默认列映射"""
    
def _transform_wechat_data(self, df: pd.DataFrame) -> pd.DataFrame:
    """微信数据自动转换"""
    df['金额'] = df['金额'].str.replace('¥', '')
    df['类型'] = df['类型'].map(lambda x: '收入' if '收入' in str(x) else '支出')
    return df
```

|------|---------|---------|
| 文件异常 | 导入文件不存在 | FileNotFoundError，显示'文件不存在'提示 |
| 文件异常 | 编码错误 | UnicodeDecodeError，提示使用正确编码 |
| 文件异常 | 空文件 | EmptyDataError，提示文件无数据 |
| 文件异常 | CSV解析错误 | ParserError，提示格式错误 |
| 数据异常 | 金额非数字 | 输入验证，阻止提交 |
| 数据库异常 | 连接失败 | 自动创建，提示用户 |
| 数据库异常 | 保存失败 | 回滚事务，显示错误提示 |
| 安全异常 | SQL注入风险 | 参数化查询 |

### 8.2 错误提示设计

```python
# 精细化异常处理示例
try:
    df = pd.read_csv(file_path, encoding='utf-8')
except FileNotFoundError:
    messagebox.showerror('文件错误', '选择的文件不存在')
    return
except UnicodeDecodeError:
    messagebox.showerror('编码错误', '文件编码错误，请尝试使用UTF-8编码')
    return
except pd.errors.EmptyDataError:
    messagebox.showinfo('空文件', '选择的文件没有数据')
    return
except pd.errors.ParserError as e:
    messagebox.showerror('解析错误', f'CSV解析失败: {e}')
    return
```

### 8.3 安全设计

**SQL注入防护：**
```python
# 所有用户数据写入均使用参数化查询（? 占位符），
# 从不拼接用户输入的 SQL 值，从根本上杜绝注入
c.executemany(
    f'INSERT INTO {TABLE_NAME} (日期, 类型, 分类, 金额, 备注) VALUES (?, ?, ?, ?, ?)',
    data_tuples
)
```
