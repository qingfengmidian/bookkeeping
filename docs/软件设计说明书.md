## 2. 引言

### 2.1 编写目的
本文档描述记账本软件的总体架构、模块设计、接口设计和数据库设计，为开发人员提供实现指导。

### 2.2 设计目标
- 采用分层架构，实现高内聚低耦合
- 支持多种数据源导入，具备良好的扩展性

## 3. 系统架构设计

### 3.1 架构模式
采用**分层架构模式（Layered Architecture）**，将系统分为以下四层：

```
┌─────────────────────────────────────────────┐
│              表示层 (Presentation)            │
│  ┌─────────────┐ ┌───────────┐ ┌─────────┐  │
│  │ main_window │ │  dialogs  │ │ charts  │  │
│  └─────────────┘ └───────────┘ └─────────┘  │
├─────────────────────────────────────────────┤
│              业务逻辑层 (Business Logic)      │
│  ┌─────────────────────────────────────┐    │
│  │          record_model               │    │
│  │   (数据处理、统计计算)               │    │
│  └─────────────────────────────────────┘    │
├─────────────────────────────────────────────┤
│              数据访问层 (Data Access)         │
│  ┌─────────────────────────────────────┐    │
│  │            database                 │    │
│  │   (SQLite 数据库操作)                │    │
│  └─────────────────────────────────────┘    │
├─────────────────────────────────────────────┤
│              工具层 (Utilities)               │
│  ┌─────────────────────────────────────┐    │
│  │          constants                  │    │
│  │   (常量、配置)                       │    │
│  └─────────────────────────────────────┘    │
└─────────────────────────────────────────────┘
```

### 3.2 模块划分

| 模块名 | 路径 | 职责 |
|--------|------|------|
| 主入口 | main.py | 程序启动，初始化GUI |
| 主窗口 | ui/main_window.py | 主界面、事件处理、业务协调 |
| 对话框 | ui/dialogs.py | 各类弹窗（筛选、编辑、预览等） |
| 图表 | ui/charts.py | 数据可视化 |
| 数据模型 | model/record_model.py | 数据处理和统计计算 |
| 数据库 | db/database.py | 持久化存储 |
| 常量 | utils/constants.py | 全局配置 |

### 4.2 业务逻辑层设计

#### 4.2.1 数据处理模块 (record_model.py)

**process_monthly(df: DataFrame) -> DataFrame**
```
输入: 原始账单DataFrame
处理:
  1. 复制数据避免副作用
  2. 日期列转为datetime
  3. 提取年月字段
  4. 透视表汇总: index=年月, columns=类型, values=金额
  5. 添加总收入、总支出列
输出: 月度汇总DataFrame
```

**process_detail(df: DataFrame, month: str) -> DataFrame**
```
输入: 原始账单DataFrame, 目标月份(YYYY-MM)
处理:
  1. 复制数据
  2. 日期列转为datetime
  3. 提取年月字段
  4. 筛选指定月份数据
输出: 当月明细DataFrame
```

#### 4.4.2 支付宝导入特殊处理
```python
# 1. 跳过前24行说明
df = pd.read_csv(file_path, encoding='gbk', skiprows=24, usecols=range(7))

# 2. 自动列映射（中英文兼容）
default_map = {
    '日期': '交易时间',
    '类型': '收/支', 
    '分类': '交易分类',
    '金额': '金额',
    '备注': '商品说明'
}

# 3. 数据标准化
df['类型'] = df['类型'].map(lambda x: '收入' if '入' in str(x) else '支出')
```

#### 4.4.3 微信导入特殊处理
```python
# 1. 跳过前16行，从第17行读取
df = pd.read_excel(file_path, header=16, usecols=[0, 2, 3, 4, 5])

# 2. 去除金额中的¥符号
df['金额'] = df['金额'].str.replace('¥', '')

# 3. 类型映射
df['类型'] = df['类型'].map(lambda x: '收入' if '收入' in str(x) or '入账' in str(x) else '支出')
```

### 6.2 持久化设计

**SQLite 数据库设计：**

```sql
-- 主表：records
CREATE TABLE IF NOT EXISTS records (
    id INTEGER PRIMARY KEY AUTOINCREMENT,  -- 自增主键
    日期 TEXT,                              -- 日期字符串
    类型 TEXT,                              -- 收入/支出
    分类 TEXT,                              -- 分类名称
    金额 REAL,                              -- 金额数值
    备注 TEXT                               -- 备注文本
);

-- 索引设计
CREATE INDEX IF NOT EXISTS idx_date ON records(日期);
CREATE INDEX IF NOT EXISTS idx_type ON records(类型);
CREATE INDEX IF NOT EXISTS idx_category ON records(分类);
```

## 8. 异常处理设计

### 8.1 异常分类

| 类别 | 异常场景 | 处理方式 |
|------|---------|---------|
| 文件异常 | 导入文件不存在/格式错误 | 显示错误对话框 |
| 数据异常 | 金额非数字、日期格式错误 | 输入验证，阻止提交 |
| 数据库异常 | 连接失败、表不存在 | 自动创建，提示用户 |
| 内存异常 | DataFrame操作失败 | 捕获异常，回滚操作 |

### 8.2 错误提示设计

```python
# 输入验证错误
try:
    amount = float(amount_str)
except ValueError:
    messagebox.showerror('输入错误', '金额必须为数字')

# 导入错误
try:
    df = pd.read_csv(file_path)
except Exception as e:
    messagebox.showerror('导入失败', f'导入过程中发生错误: {e}')

# 删除确认
if not messagebox.askyesno('确认删除', '确定要删除选中的账单吗？'):
    return

# 未保存提示
if self.dirty:
    res = messagebox.askyesnocancel('未保存更改', '是否保存后退出？')
```
