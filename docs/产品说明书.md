## 一、产品简介

记账本（bookkeeping）是一款安装在电脑上的单机记账软件。它用一张简单的表格帮你记录每一笔收入和支出，并自动算好总收入、总支出，还能画出柱状图和饼图，让你一眼看清钱花在了哪里。

**它解决什么问题：**

- 手工记账太麻烦：打开软件，填几个格子，点一下「添加」，一笔账就记好了。
- 翻旧账太难：所有记录在一个列表里，可以按日期、金额、类型、分类筛选，点一下表头还能排序。
- 支付宝、微信的账单分散在两个 App 里：软件支持直接导入支付宝 CSV 账单和微信 Excel 账单，省去逐条手输。
- 月底对不上数：统计菜单可以按月汇总，图表直观展示每月收支对比和分类占比。

**适合谁用：**

- 想搞清楚自己每月收支情况的个人用户；
- 需要同时记多个账本（比如个人账、家庭账分开）的用户；
- 习惯用支付宝、微信消费，希望把电子账单统一汇总分析的用户。

本软件是单机版应用，不需要联网，数据全部保存在你自己的电脑上。

## 三、安装与启动

软件提供三种使用方式，任选其一。

### 方式一：Windows 免安装版（推荐）

1. 到本项目的 Releases 页面下载 `bookkeeping.exe`。
2. 这是一个单文件程序，不需要安装，也不需要在电脑上装 Python。双击即可运行。
3. 数据保存在 exe 同目录的 `database` 文件夹中。建议把 exe 放在一个固定的文件夹里，不要随手放在桌面后频繁移动，否则数据库位置会跟着变。
4. **首次运行注意事项**：Windows 可能弹出「未知发布者」的蓝色提示（因为程序没有购买代码签名证书）。点击「更多信息」→「仍要运行」即可，这不代表软件有问题。

### 方式二：Linux 解压版

1. 下载 `bookkeeping-linux-x86_64-<版本>.tar.xz`，例如 `bookkeeping-linux-x86_64-v0.1.0.tar.xz`。
2. 解压：

   ```bash
   tar -xJf bookkeeping-linux-x86_64-v0.1.0.tar.xz
   cd bookkeeping
   ```

3. 运行：`./bookkeeping`
4. 同目录下的 `.sha256` 文件可用于校验下载是否完整（用 `sha256sum -c` 命令）。
5. **首次运行注意事项**：数据保存在启动目录的 `database` 文件夹中。请固定在一个目录下启动，不要在不同目录之间来回切换，否则每换一个启动目录就会新建一套 `database`。

### 方式三：从源码运行

适合开发者或需要最新代码的用户。

1. 安装 Python 3.8 或更高版本。
2. Linux 需先安装 tkinter 系统包，例如 Ubuntu/Debian：

   ```bash
   sudo apt install python3-tk
   ```

3. 创建虚拟环境并安装依赖：

   ```bash
   # macOS / Linux
   python3 -m venv venv
   ./venv/bin/pip install -r requirements.txt
   ```

   ```powershell
   # Windows（PowerShell）
   python -m venv venv
   .\venv\Scripts\pip install -r requirements.txt
   ```

4. 启动：

   ```bash
   # macOS / Linux
   ./venv/bin/python main.py
   # Windows
   .\venv\Scripts\python main.py
   ```

**首次运行通用注意事项**：无论哪种方式，第一次启动时如果默认数据库还不存在，软件会弹窗提示「将在以下位置新建数据库文件：……/database/root.db」，确认后即自动创建，之后无需再管。

## 四、快速上手：五分钟记下第一笔账

1. 启动软件，你会看到主窗口：上方是输入区，中间是账单表格，下方是删除按钮和统计栏。
2. 在输入区依次填写：
   - **日期**：默认是今天，点右边的下拉箭头可以从日历中选其他日期；
   - **类型**：点下拉框选「支出」或「收入」；
   - **分类**：点下拉框选一个分类（餐饮、交通、购物、娱乐、医疗、住房、学习、工资、其他）；
   - **金额**：直接输入数字，例如 `25.5`；
   - **备注**：可写可不写，比如「午餐」。
3. 点击最右边的「添加」按钮。会弹出「账单添加成功！」，同时表格里立刻多出一行，底部「总支出」数字也自动更新。
4. 连续多记几笔：添加成功后金额和备注会自动清空、日期回到今天，直接接着填下一笔即可。
5. 记完后点击菜单栏「文件 → 保存」，看到「数据已成功保存！」就大功告成。下次打开软件数据还在。

> 小提示：如果没有手动保存就关窗口，软件会提醒你「当前数据尚未保存，是否保存后退出？」，选「是」即可，不会丢数据。

## 五、功能详解

### 5.1 新增账单

- **从哪里进入**：主窗口顶部输入区。
- **怎么操作**：填写日期（日历控件选择）、类型、分类（均为下拉选择）、金额、备注（选填），点击「添加」。
- **会看到什么**：弹出「账单添加成功！」，表格立即新增一行，底部总收入/总支出随之刷新，收入行以绿色显示、支出行以墨色显示，表格带斑马纹方便逐行查看。
- **注意**：金额必须填数字，填文字会提示「金额必须为数字」；日期、类型、分类为必填。

### 5.2 编辑账单

- **从哪里进入**：主窗口中间的账单表格。
- **怎么操作**：用鼠标**双击**要修改的那一行，会弹出「编辑账单」对话框，五个字段都可以改，改完点「保存」。
- **会看到什么**：修改自动写入数据库并保存（无需再手动点保存），表格刷新为新内容。
- **注意**：金额同样必须是数字，否则会提示错误且无法保存。

### 5.3 删除账单

- **从哪里进入**：表格下方的两个按钮。
- **怎么操作（删除选中）**：先在表格里点选一行（按住 Ctrl 键再点可以多选），然后点「删除选中账单」，弹出确认框，点「是」删除。
- **怎么操作（删除全部）**：点「删除全部」，在确认框中点「是」，清空当前账本的所有账单。
- **会看到什么**：表格刷新，弹窗提示已删除多少条。底部统计数字同步更新。
- **注意**：删除操作不可撤销，请谨慎使用「删除全部」。删除后需要点「文件 → 保存」才会真正写回数据库（关闭窗口时软件也会提醒保存）。

### 5.4 筛选与排序

- **筛选从哪里进入**：菜单栏「筛选 → 筛选账单」。
- **筛选怎么操作**：在弹窗中设置条件——
  - 起始日期、结束日期（日历选择，留空表示不限）；
  - 最小金额、最大金额（只填一个表示单边限制）；
  - 类型：全部 / 支出 / 收入；
  - 分类：全部或具体分类。
  
  设置好点「应用筛选」；想恢复全部数据，点「清除筛选」。
- **筛选会看到什么**：表格只显示符合条件的行，不符合的行暂时隐藏（数据没有丢）。
- **排序怎么操作**：点击表格任意一个列标题（日期、类型、分类、金额、备注）。第一次点击升序排列，再点同一列切换为降序，再点又变回升序，如此循环。
- **注意**：排序和筛选可以同时生效；筛选中的「金额」一栏必须填数字，否则会提示「最小/最大金额必须为数字」。

### 5.5 统计图表

- **月度账单**：菜单「统计 → 月度账单」。弹窗按月份列出收入、支出、总收入、总支出四列，点击表头可排序；**双击某个月**可查看该月的全部收支明细（同样可以点表头排序）。

- **月度收支柱状图**：菜单「统计 → 统计图表 → 月度收支柱状图」。弹窗中用绿色柱表示每月收入、墨色柱表示每月支出，直观对比各月收支。

- **单月收支饼状图**：菜单「统计 → 统计图表 → 单月收支饼状图」。先在弹窗中下拉选择一个月份，点「确定」，会看到该月「支出分类」和「收入分类」两个饼图，各占多少比例一目了然。窗口底部有「← 上一月」「下一月 →」按钮可以按月翻看；翻到最早或最晚的月份时，对应按钮会变灰不可用。

- **会看到什么**：如果没有数据，会提示「没有可统计的账单数据。」；某个月只有支出没有收入时，收入饼图位置显示「无收入数据」，反之亦然。

### 5.6 多数据库（账本）管理

软件可以把不同用途的账目存在不同的数据库文件里，随时切换。

- **新建账本**：菜单「文件 → 新建」。如果有未保存的修改，会先问你是否保存；然后在文件对话框中为新账本起名（扩展名 `.db`），保存后自动切换到新账本，状态栏右下角显示新路径。
- **打开账本**：菜单「文件 → 打开」。文件对话框默认定位到 `database` 目录，选中一个 `.db` 文件打开，表格立刻换成那个账本的内容。
- **保存**：菜单「文件 → 保存」。把当前表格里的全部数据写入当前数据库。
- **另存为**：菜单「文件 → 另存为」。把当前数据复制保存到一个新的 `.db` 文件，保存后软件自动切换到这个新文件继续工作。
- **怎么知道当前用的是哪个账本**：看主窗口最底部右侧的「当前数据库: …」，路径过长时会自动截断，只显示后半部分。
- **注意**：新建或打开其他账本前若有未保存的修改，软件都会先提醒保存，防止误丢数据。

### 5.7 导出 CSV

- **从哪里进入**：菜单「导出 → CSV」。
- **怎么操作**：选择保存位置和文件名，点保存。
- **会看到什么**：弹出「数据已导出到 …」，得到一个 CSV 文件，可用 Excel、WPS 或记事本打开。导出采用 UTF-8 编码（带 BOM），Excel 直接打开不会乱码。
- **用途**：把账本数据发给他人，或者用 Excel 做进一步分析。

### 5.8 语言与字号设置
- **切换界面语言**：菜单「语言 → 中文」或「语言 → English」，立即生效，重启后保持。
  - 注意：语言只影响界面文字。账单数据里的分类、收支类型始终保持中文，不受切换影响。
- **调节字号**：菜单「设置 → 菜单字号」和「设置 → 界面字号」。菜单字号可选「跟随界面 / 12 / 14 / 16 / 18 / 20」；界面字号可选「默认 / 12 / 14 / 16 / 18 / 20」。当前生效的选项前带有「√」标记。
- **会看到什么**：字号调整后立即生效，无需重启；重启软件后设置依然保持（保存在 `database/settings.json` 中）。

### 5.9 数据库加密（v0.1.0 新增）

软件支持为账本文件设置密码加密。加密后账本以密文保存在磁盘上，没有密码的人（包括用其他工具直接打开 .db 文件）无法查看任何账目；打开、保存等日常操作与明文账本完全一致。

- **加密当前账本**：菜单「文件 → 加密当前账本」。输入并确认密码（少于 6 位会提示弱密码），确认风险提示后完成。有未保存的修改时需先保存，菜单项才会可用。
- **打开加密账本**：「文件 → 打开」选择密文 .db 时自动弹出密码输入框，最多可重试 5 次。默认数据库 root.db 被加密后，下次启动软件时会先要求输入密码。
- **新建加密账本**：「文件 → 新建」选择位置后会询问"是否为该账本设置密码加密"，选"是"并设置密码即可。
- **解密**：菜单「文件 → 解密当前账本」，验证密码后账本恢复为明文。
- **修改密码**：菜单「文件 → 修改密码」，验证原密码后设置新密码。
- **另存为**：加密账本另存为的新文件会沿用当前密码自动加密；明文账本另存为仍是明文。
- **技术说明**：AES-256-GCM 整文件加密，PBKDF2-HMAC-SHA256（60 万次迭代）派生密钥，文件头只保存 salt/nonce 等参数，不保存密码；写盘采用临时文件 + 原子替换，加密中断不会损坏原账本。

> ⚠️ **重要：忘记密码将无法恢复数据，软件没有后门**。加密成功后请牢记密码，重要数据仍建议定期备份 `database` 文件夹（备份的是密文，可以整份备份）。

## 六、账单导入

软件支持三种导入方式。导入的流程都是一样的：选择文件 → 确认列对应关系 → 预览数据 → 确认导入。预览窗口显示前 10 行，窗口底部显示总记录数；预览中**双击某一行可以修改**该行的内容，点表头可以排序。确认无误后点「确认导入」，点「取消」则放弃。

软件安装包附带 `examples` 目录，里面有匿名化合成的示例账单（CSV、支付宝、微信各若干份），可以用来先练手。

### 6.1 标准 CSV 导入

**格式要求**：文件必须是 UTF-8 编码的 CSV，第一行为表头，包含「日期、类型、分类、金额、备注」五列，例如：

```csv
日期,类型,分类,金额,备注
2025-01-01,收入,工资,10000,无
2025-01-02,支出,吃饭,100,无
```

日期格式如 `2025-01-01`；类型填「收入」或「支出」。

**操作步骤**：菜单「导入 → CSV」→ 选择文件 → 软件自动匹配列 → 确认映射 → 预览 → 确认导入。

**常见失败原因**：
- 文件不是 UTF-8 编码（比如是 Excel 另存的 GBK 编码 CSV）→ 提示「文件编码错误，请尝试使用UTF-8编码保存文件」。解决办法：用记事本或 Excel 把文件另存为 UTF-8 编码。
- 文件是空的 → 提示「选择的文件没有数据」。
- 内容不是规范的 CSV（逗号错乱）→ 提示「CSV解析失败」。

### 6.2 支付宝账单导入

**格式要求**：从支付宝官方导出的账单 CSV 文件（通常为 GBK 编码）。软件会自动跳过文件开头的 24 行说明文字，自动把「交易时间」对应到日期、「收/支」对应到类型、「交易分类」对应到分类、「金额」对应到金额、「商品说明」对应到备注；英文版账单（Date / In/Out / Product / Amount(¥) / Remark 等列名）也能自动识别。交易分类为空的记录，分类会自动填为「支付宝」。

**操作步骤**：菜单「导入 → 导入支付宝账单」→ 选择支付宝导出的 CSV → 检查并确认列映射 → 预览（可双击修正）→ 确认导入。

**常见失败原因**：
- 文件被手工改过、行数对不上 → 提示「CSV解析失败，请确认是支付宝账单格式」。请使用支付宝官方导出的原始文件。
- 文件被转存成了 UTF-8 → 提示编码错误（支付宝账单通常使用 GBK 编码）。
- 选错了文件（比如选了微信账单）→ 解析失败提示。

### 6.3 微信账单导入

**格式要求**：从微信官方导出的 Excel 文件（`.xls` 或 `.xlsx`）。软件自动跳过前 16 行说明文字，从第 17 行开始读取；自动把「交易时间」对应到日期、「收/支」对应到类型、「交易对方」对应到分类、「金额(元)」对应到金额（自动去掉 ¥/￥ 符号）、「商品」对应到备注；也兼容「金额（元）」的全角括号写法和英文列名（Date / Type / Category / Amount / Description）。交易对方为空的记录，分类自动填为「微信」。

**操作步骤**：菜单「导入 → 导入微信账单」→ 选择微信导出的 Excel → 确认列映射 → 预览 → 确认导入。

**常见失败原因**：
- 选成了 CSV 或其他文件 → 提示「Excel格式错误或缺少必要列」。
- 文件被手工编辑过、表头行错位 → 列映射对不上，请在列映射弹窗中手动调整每一列对应的列。

**导入通用注意**：确认导入后，数据进入表格并标记为「已修改」，记得点「文件 → 保存」写回数据库。若重复导入了同一份文件，可以用筛选 + 删除功能去重。

## 七、数据存储与备份

**数据存在哪里：**
所有账单保存在一个 SQLite 数据库文件中。默认位置是软件所在目录下的 `database/root.db`。打包版（exe / Linux 可执行文件）的数据库、设置、语言文件都锚定在可执行文件所在目录，不随启动时的当前目录变化。

**配置文件：**
- `database/settings.json`：字号等界面设置；
- `database/i18n.lang`：界面语言选择。

**日志在哪里：**
软件运行日志记录在软件所在目录下的 `logs/bookkeeping.log`，采用追加模式不断写入。遇到异常或想排查「我刚才的操作到底成功没有」，可以用记事本打开这个文件查看。日志不会自动清理，需要时可手动删除以释放空间。

**怎么备份 / 换电脑：**
最简单的方法就是备份整个 `database` 文件夹。换电脑时：
1. 在新电脑上安装并启动一次软件（让它自动建好目录结构）；
2. 把旧电脑上的 `database` 文件夹整个复制过来，覆盖新目录；
3. 重新启动软件即可看到全部数据。
也可以只复制某个 `.db` 文件，在新电脑上通过「文件 → 打开」载入。

> 提醒：软件不会自动备份，重要数据请定期手动复制 `database` 文件夹到 U 盘或网盘。

## 八、常见问题 FAQ

1. **关窗口的时候弹出「当前数据尚未保存，是否保存后退出？」是什么意思？**
   说明你有新增、删除或导入的账目还没写入数据库。点「是」先保存再退出；点「否」直接退出，未保存的修改会丢失；点「取消」返回软件继续操作。

2. **我记了一笔账，重启软件后不见了？**
   多半是没有保存。添加、删除、导入后请点「文件 → 保存」（编辑账单会自动保存）。如果误点了「否」退出，未保存的数据无法找回。

3. **点「添加」提示「金额必须为数字」，可我觉得填的就是数字？**
   检查金额框里有没有混入中文、空格或货币符号（如「￥50」「50元」）。只输入纯数字，如 `50` 或 `50.5`。

4. **导入支付宝账单提示「CSV解析失败，请确认是支付宝账单格式」？**
   说明文件不是支付宝官方导出的原文件，或被其他软件转存过。请重新从支付宝导出账单后再导入，不要先用 Excel 打开另存。

5. **导入 CSV 提示「文件编码错误」？**
   标准 CSV 导入要求 UTF-8 编码。用记事本打开文件，选择「另存为」，编码选 UTF-8，再导入即可。

6. **删除错了怎么办？**
   删除前有确认框，点击「是」之后不可撤销。如果还没保存，直接退出软件并选择「不保存」，可恢复到上次保存的状态；已保存的删除则无法恢复，所以删除重要数据前建议先「文件 → 另存为」留一个副本。

7. **双击行没反应，编辑不了？**
   请确认双击的是表格中有数据的行（不是表头）。如果当前正在筛选状态且该行数据已被删除，软件会忽略这次编辑。也可以先清除筛选再试。

8. **柱状图或饼图弹不出来，提示「没有可统计的账单数据。」？**
   当前账本还没有账单记录。先添加或导入一些数据再查看图表。

9. **界面切换成英文后看不懂了，怎么换回来？**
   菜单栏第六个菜单（Language）→ 选「中文」，立即恢复。

10. **窗口缩小后表格列被挤得看不全？**
    表格下方有横向滚动条，拖动即可查看所有列；把窗口拉大，列宽会自动跟随调整。窗口最小为 720×480，不会小到看不见控件。

11. **想在公司电脑和家里电脑各记一本账，可以吗？**
    可以。用「文件 → 新建」建多个 `.db` 文件（如 `home.db`、`work.db`），通过「文件 → 打开」随时切换。

12. **忘记加密密码怎么办？**
    无法恢复。加密采用 AES-256-GCM，密码是唯一密钥，软件不保存密码也没有后门。请务必牢记密码；如果担心忘记，可以先用「文件 → 另存为」留一份明文副本存放在安全的地方。

13. **加密后还能正常记账、导入、导出吗？**
    可以。加密只影响磁盘上的存储格式，软件内所有功能（记账、导入、导出、统计图表）与明文账本完全一致。

## 九、卸载与清理

本软件不写系统注册表、不在系统目录留文件，卸载非常简单：

1. 关闭软件。
2. Windows 免安装版：直接删除 `bookkeeping.exe` 所在文件夹即可。
3. Linux 版：删除解压出来的 `bookkeeping` 文件夹即可。
4. 如果确定不再需要账目数据，连同文件夹里的 `database`（数据与设置）和 `logs`（日志）一起删除即完成全部清理；如想保留数据，请先按第七章备份。

从源码运行的环境，删除项目文件夹，并可顺手删除之前创建的虚拟环境文件夹（`venv`）即可。
